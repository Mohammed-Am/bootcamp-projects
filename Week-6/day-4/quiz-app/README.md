# Interactive Quiz App

A modern, interactive quiz application built with Node.js, Express, EJS, and SQLite.

## Features

- Take quizzes and see your score
- Admin panel to manage questions (coming soon)
- Modern, responsive UI

## Tech Stack

- Node.js, Express
- EJS (templating)
- SQLite (database)
- HTML, CSS, JavaScript

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the server:
   ```bash
   node app.js
   ```
3. Open your browser at [http://localhost:3000](http://localhost:3000)

## Folder Structure

```
quiz-app/
├── public/           # Static files (CSS, client JS, images)
├── views/            # EJS templates
├── routes/           # Express route files
├── db/               # Database file
├── app.js            # Main Express app

```
